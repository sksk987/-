# קריינית סיעתא – Android

אפליקציה אישית בעברית המבוססת על WebView ומחוברת לאתר https://siata-voice-studio.a0548598728.workers.dev/ .

### יצירת APK
הבנייה נעשית ללא תשלום ב-GitHub Actions. פתחו את לשונית **Actions** והורידו את **SiataVoice-Android-APK** מההרצה המוצלחת האחרונה. יש לחלץ את הקובץ APK מה-ZIP.

### אבטחה
מפתח ה-Gemini API אינו מובנה ב-APK. הוא מוזן על ידי המשתמש. אם בוחרים 'זכור את המפתח', הוא נשמר באחסון המקומי של WebView, לא מוצפן. המלצה: לא לזכור מפתח במכשיר משותף. ה-APK דורש חיבור אינטרנט.

### קוד פתוח
כל קוד המעטפת זמין כאן. שירות האתר בנוי על Cloudflare Workers וקודו נשמר בחשבון Cloudflare של בעל האפליקציה.
